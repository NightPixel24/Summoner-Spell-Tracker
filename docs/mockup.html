How this mockup behaves

  • Tap a spell → icon goes grey, colour sweeps back clockwise like a clock hand, black countdown on top.
  • Long-press a running timer → reset to ready.
  • Pencil → edit mode (tiles wiggle, spell pool appears). Tap a slot, then a pool spell to swap. A swapped slot's timer resets.
  • Cog → settings sheet to edit each spell's cooldown.

Icons here are placeholder tiles. The real app loads the official summoner spell icons from Riot's Data Dragon CDN.
